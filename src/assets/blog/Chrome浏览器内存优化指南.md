> 适用环境:Windows 10 + Chrome 151
> 目标:在不牺牲稳定性的前提下,把 Chrome 的内存占用压到健康水平(日常 1~1.5 GB)

---

## 一、先理解:Chrome 为什么吃内存

Chrome 是"多进程架构"——不是一个大程序,而是"一个总管 + 一群工人":

| 进程 | 职责 | 说明 |
|------|------|------|
| 主进程 | 窗口、地址栏、标签栏 | 每个浏览器 1 个 |
| GPU 进程 | 把网页画面画出来(硬件加速) | 每个浏览器 1 个 |
| 网页渲染进程 | 网页内容 | **每个标签页 1 个** |
| 扩展进程 | 扩展后台运行 | **每个扩展 1 个** |
| 网络/存储服务 | 上网、Cookie | 各 1 个 |

设计初衷:每个标签页独立成进程,一个网页崩溃不影响其他网页。代价就是——**标签页越多、扩展越多,内存越大**。每个进程哪怕内容再少,也有约 30~100 MB 的"底价"。

**结论:开几个标签页就占几百 MB 是正常现象,不是电脑坏了。**

---

## 二、先分析:到底谁在吃内存

### 方法 1:Windows 任务管理器(粗略)

Ctrl+Shift+Esc → 进程列表,按"内存"排序,看 Chrome 组的总占用。

### 方法 2:Chrome 自带任务管理器(精确,推荐)

在 Chrome 里按 **Shift + Esc**(或:右上角 ⋮ → 更多工具 → 任务管理器)。

列表会显示**每个标签页和每个扩展**的内存占用,点"内存占用空间"列排序,最大的就是内存大户。

### 方法 3:看整机内存是否够用(判断要不要优化)

Windows 任务管理器 → 性能 → 内存,看总内存和可用量。

判断标准不是"Chrome 占了多少",而是"系统还剩多少"。剩 30% 以上就不用焦虑。

---

## 三、优化方法(按性价比排序)

### 1. 关掉不用的标签页(最直接)

开 10 个标签页只用 1 个,剩下 9 个都在白吃内存。用不到就关,或用 OneTab 收纳(见第 7 条)。

### 2. 启用"内存节省程序"(官方功能)

地址栏输入 `chrome://settings/performance` 回车 → 打开 **"内存节省程序"**。

效果:长时间不看的标签页自动"休眠",用的时候再唤醒,内存直接降一大截。

### 3. 关闭"预加载网页"(隐形大户,默认开着)

同页面(性能设置)→ "预加载" → 选 **"标准预加载"** 或直接关闭。

原因:默认会在鼠标悬停链接时**提前加载整个网页**,扫过的每个链接都可能吃几十 MB,但 90% 的链接根本不会点。

### 4. 关闭"后台运行"(关窗口≠退出,默认开着)

地址栏输入 `chrome://settings/system` 回车 → 关闭 **"关闭 Google Chrome 后继续运行后台应用"**。

原因:默认关掉所有窗口后,Chrome 还躲在右下角托盘里继续跑(收通知、后台下载)。要退出就彻底退出,托盘图标右键 → 退出。

### 5. 启动时别自动恢复一堆标签页

地址栏输入 `chrome://settings/on-startup` 回车 → 选 **"打开新标签页"**。

原因:如果设置成"继续上次的会话",每次启动 Chrome 会一次性恢复几十个标签页,瞬间吃满内存。

### 6. 管理扩展(停用 vs 卸载)

地址栏输入 `chrome://extensions` 回车,每个扩展右边有开关。

| | 停用(关开关) | 卸载(移除) |
|---|---|---|
| 还占内存吗 | 不占(进程不启动) | 不占 |
| 想再用回来 | 一键重新启用 | 去商店重新安装 |
| 设置和数据 | 保留 | 全删 |
| 适合场景 | 暂时不用 / 不常用 | 确定再也不用了 |

规则:内存效果一样,区别只是"要不要留后路"。不确定就停用,确定不用才卸载。

### 7. 用 OneTab 收纳标签页(神器)

OneTab 扩展:点一下工具栏图标,**所有标签页收成一个列表**(网页彻底卸载,只留标题),内存立刻归零。想用哪个再点开。

比"内存节省程序"更彻底——休眠的标签页还占一点,OneTab 是彻底不加载。

### 8. 定期重启 Chrome(习惯)

网页开久了内存碎片和泄漏会累积(尤其视频站、大网页)。每天彻底退出一次 Chrome(托盘右键 → 退出),第二天就清爽。

## 四、进阶手段(不推荐,副作用明显)

### --process-per-site(减少进程数量)

右键 Chrome 快捷方式 → 属性 → 目标一栏最后加 ` --process-per-site`(前面有空格)。

效果:开 10 个同网站标签页,从 10 个进程变 1 个。
代价:**一个网站崩溃,该网站所有标签页一起崩**。且单个进程内存变大,实际省不了多少。不建议。

### 加内存条(治本,花钱)

16GB 是"够用但偏紧":Chrome + VS Code + WSL + 杀毒同时跑,占用约 8GB。经常多开的话,加到 32GB 一劳永逸。这是唯一真正"彻底解决"的办法。

---

## 五、认清一个事实:Chrome 可能不是你机器的内存大户

优化后的典型占用排行(16GB 机器):

```
VS Code          约 460 MB
WSL 虚拟机(vmmem) 约 360 MB
Windows 杀毒      约 360 MB
Chrome           约 1.1 GB(优化后)
```

Chrome 优化到 1~1.5 GB 就是它的健康水平,再压下去要么牺牲稳定性要么花钱,性价比很低。真觉得卡,OneTab 收标签页 + 重启浏览器,5 秒钟的事。

## 六、Windows 自带杀毒(Defender)要不要关?

### 先看数据(以本机为例)

- 实时保护正常工作,但 CPU 累计占用约 **0 秒**(几乎不干活)
- 内存占用几百 MB,是"待命"状态,平时很轻
- Win10 22H2 有"篡改保护":手动关闭后系统会自动重新打开,还弹红色警告

### 为什么不建议关

杀毒软件像保险——平时感觉不到,是因为它一直在默默挡着。每天用 Chrome 下载、插 U 盘、开软件都是病毒入口。Defender 免费、内置、几乎不占资源,是系统最后防线。**关掉 = 裸奔上网**。注意:很多"教你关闭 Defender"的教程/工具本身就是病毒传播手段。

### 临时关闭(推荐,够用)

开始菜单 → 搜索"Windows 安全中心" → 病毒和威胁防护 → 关闭 **"实时保护"** 开关。

效果:关掉后几小时到几天内自动重新打开。适合"怕大型软件被误拦"的场景。

### 永久关闭(不推荐,但记录方法)

系统必须是**专业版**(家庭版没有组策略)。

1. 按 `Win+R`,输入 `gpedit.msc` 回车
2. 左侧依次展开:计算机配置 → 管理模板 → Windows 组件 → Microsoft Defender 防病毒
3. 右侧双击 **"关闭 Microsoft Defender 防病毒"**
4. 选 **"已启用"** → 确定

副作用:任务栏出现红色盾牌警告、Windows 安全中心全程报警、Windows 更新时可能被强制改回去(需重设)、系统失去防护。

### 恢复方法

同一个位置(`gpedit.msc` 的同一项)改回 **"未配置"** → 确定即可。
